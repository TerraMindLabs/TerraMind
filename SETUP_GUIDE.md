# TerraMind: Agent Configuration Guide

Once you have successfully run the installer (`install-tf-ai.sh` or `install-tf-ai.ps1`) and your application is running at `http://localhost:3080`, follow these final steps to activate your AI Cloud Architect.

## 🤖 Step 1: Login
Because of TerraMind's **Zero-Click Agent Deployment**, the AI Agent and its Terraform instructions are already built into your database!
1. Open your browser and navigate to `http://localhost:3080`.
2. Create your admin account and log in.

## ⚡ Step 2: Activate Your Agent
Instead of building the agent from scratch, you can simply activate it from the Agent Marketplace:
1. On the left sidebar, click on **Agents**.
2. Because the agent was pre-installed as a "Promoted" agent, you will immediately see the **Terraform DevOps Expert** waiting for you.
3. Click on the Agent to activate it. 
*(Note: It is already pre-configured with the correct instructions, models, and MCP tools!)*

## 🎉 Step 3: Test it Out!
Open a new chat, ensure your **Terraform DevOps Expert** agent is selected, and type:
> *"Create a highly available AWS VPC with two public and two private subnets, and save the files to my workspace. Please run a complete end to end validation when you are done."*

Watch as the AI plans the architecture, writes the code to your local machine, formats it, checks for security flaws, and validates it against the Terraform binary!
